# تصاویر

تصاویر استاتیک اپ: لوگو، تصاویر جایگزین (placeholder)، تصاویر اوگر و …

## فایل‌های فعلی

| فایل              | کاربرد                          |
| ----------------- | ------------------------------ |
| `logo.svg`        | لوگوی یوما در سایدبار           |
| `logo-mark.svg`   | نشانه لوگو (فقط علامت) برای حالت جمع‌شده سایدبار |
| `empty-state.svg` | تصویر پیش‌فرض حالت خالی          |

## نکته

تصاویر داینامیک (مثل عکس سفارش‌ها) از طریق `next/image` از آدرس API
بارگذاری می‌شوند — تنظیمات `remotePatterns` در `next.config.js`.
