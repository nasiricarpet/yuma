# آیکون‌ها

آیکون‌های SVG ایستا (غیر از آیکون‌های `lucide-react` که به‌صورت پکیج نصب شده‌اند).

## قرارداد

- فرمت: `svg` با `stroke="currentColor"` برای هم‌رنگ شدن با متن
- نام‌گذاری: `kebab-case` — مثال: `carpet-wash.svg`
- بهتر است `width`/`height` نداشته باشند تا با کلاس‌های Tailwind اندازه‌گیری شوند

## استفاده

```tsx
import carpetWash from '@/public/icons/carpet-wash.svg';
```
